Repositorio oficial de materiales, laboratorios prácticos y plantillas de auditoría para la formación profesional orientada a la empleabilidad en ciberseguridad defensiva (*Blue Team* / Soporte SOC Junior)[cite: 6, 13].

---

## 🗺️ Estructura del Programa (25 Horas)

| Bloque | Horas | Contenidos Clave | Entregable de Portfolio |
| :--- | :---: | :--- | :--- |
| **Bloque 1** | 10h | Ecuación del riesgo, Tríada CID, Zero Trust, MFA, Mínimo Privilegio y Auditoría PYME | Matriz de Riesgos (*Transporte y Logística Sur S.L.*) + Política IAM |
| **Bloque 2** | 10h | Bastionado (*Hardening*) de puestos y móviles, Segmentación Wi-Fi/VPN, Navegación Segura y Detección de Amenazas[cite: 5, 11, 13, 15] | Checklist CCN-STIC + Esquema de Red Segmentada |
| **Bloque 3** | 5h | Respuesta ante Incidentes (Phishing / Ransomware), Reporte INCIBE y Defensa Técnica | Playbook de Contención y Recuperación |

---

## 🛠️ Cómo usar este repositorio (Para el alumnado)

1. **Sin instalaciones:** Todos los laboratorios funcionan directamente en el navegador web o mediante hojas de cálculo estándar.
2. **Tu Portfolio Profesional:** Puedes usar la estructura de este repositorio como plantilla para publicar tus propias auditorías y políticas de seguridad en tu perfil de GitHub y enlazarlo en tu CV o LinkedIn.
